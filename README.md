# iris_flower_classification
# 🌸 Iris Flower Classification

## 📌 Project Overview

This project focuses on classifying iris flowers into different species using **Machine Learning**. The model predicts the species of an iris flower based on its sepal and petal measurements.

The project uses the popular **Iris dataset** and demonstrates the basic workflow of a Machine Learning classification problem.

## 🎯 Objective

The main objective is to build a Machine Learning model that can accurately classify iris flowers into:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

## 🤖 Machine Learning

The Iris dataset is used to train a classification model. The features include:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target variable is the **Iris species**.

## 📈 Results

The trained model was evaluated using appropriate classification metrics such as **accuracy and classification report**.

The visualizations also help understand the relationship between the different flower measurements and species.
